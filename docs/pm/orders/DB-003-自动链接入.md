# DB-003：DB-AIOps 黑板接入自动链

执行：GorkMan、A、O

## 背景

DB-001 人工叫醒证实两处断点：其一，飞书群成员目前仅用户本人，设计团队不在群内，群广播不等于成员已收到；其二，宿主机轮询守护（member_poller）与 A/O 自动领单链目前只盯 Xinchuang 黑板，未适配 DB-AIOps；分发器又因 GitHub 视图滞后看不见 DB-AIOps 板（REST 备用读数已接线，待出口放行验证）。DB-001 目前无任何自动送达通道。本单治本：把 DB-AIOps 黑板接进自动链。

## 任务

1. GorkMan（主）：member_poller 增加 DB-AIOps 仓库轮询（orders/ 与 reports/），与 Xinchuang 并行；读数失败时记警告、不静默按空处理（分发器 2026-11-04 静默吞错是前车之鉴）。
2. A：A-AUTORUN 增加 DB-AIOps 黑板监听，不改现有 Xinchuang 行为。
3. O：WAKE-O-AUTO 增加 DB-AIOps 黑板监听，不改现有 Xinchuang 行为。
4. 分发器 DB-AIOps 广播验证（GorkMan 汇总）：REST 出口恢复后，实测 DB-AIOps 新单能广播到飞书群；出口未恢复前，每日核对分发器对 DB-AIOps 的可见性状态并记录，不静默。
5. 全链路验收：DB-AIOps 黑板发一单测试单（测试单事后归档，不占用正式编号），从落库到分发器广播、成员自动领单全链路跑通，留验收记录。

## 接单规矩

接单后先在黑板上回预计交付时间（reports/ 下简短回执即可）；飞书群只作广播，接单确认与 ETA 一律落黑板。本单不设硬性截止；GorkMan 部分以 2026-11-05 token 恢复后起算。

## 交付

reports/DB-003-report-自动链接入.md，结论三档之一；各链路改动位置与验证方法写明；全链路验收记录附后。
