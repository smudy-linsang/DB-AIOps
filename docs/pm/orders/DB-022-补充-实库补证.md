- MySQL 分支（12 项）：`INS-COM-USER-LOCKED`、`INS-COM-PWD-EXPIRE`、`INS-COM-CAP-7D`、`INS-COM-CAP-30D`、`INS-COM-DEADLOCK-24H`、`INS-COM-MISSING-INDEX`、`INS-COM-SPARSE-INDEX`、`INS-COM-PART-NEEDED`、`INS-COM-PARAM-DEV`、`INS-COM-LOCK-WAIT`、`INS-COM-BLOCK-SESSION`、`INS-COM-TEMP-USAGE`——真实 MySQL 8.0.45 直连（13306，cid=19，DB-005R 同款）。

- Oracle 分支（23 项全部）：不做，外网无真实库，延至上线后内网复测；报告逐项写明"未测·延后"，不得写成通过或以 skip 充数。

每项每个分支写清：SQL 原文、实库（库名/版本/时间）、输出原文、判定（命中/未命中/skip/error）。方言不适用仍按 DB-022 报告 §二口径优雅 skip，但须以实库实测为准，不得沿用单测 mock 的结论。
