## 1. 设计理念与设计系统 (Design System)

### 1.1 核心设计理念
1. **沉浸式一体化排障**：告警、拓扑、阻塞树、根因证据与处置动作单页呈现，杜绝多 Tab 频繁切换与上下文割裂。
2. **高信噪比与信息分级**：关键 SLA 状态、Root Blocker 红色警示高亮，次要指标微光降噪。
3. **触手可及的智能协同**：全局悬浮 Copilot、右键快捷处置与 1-Click 一键智能体检。

### 2.2 【360° 性能中枢 2.0 (Performance Hub 2.0)】
- **ASH 等待事件多维透视**：
  - 采用 ECharts 支持按 `Wait Event`、`User`、`SQL ID`、`Client IP` 一键四维下钻切换。
  - 支持鼠标滚轮框选任意时间片段，毫秒级平滑刷新关联会话明细。
- **动态阻塞树 (Interactive Blocking Tree)**：
  - 树状节点直观展示多层级阻塞依赖关系；
  - 根节点以发光红圈标注 `Root Blocker`，悬停展示 SQL 详情与已阻塞总事务数；
  - 支持节点右键菜单触发：`查看 SQL 执行计划`、`跟踪客户端 IP`、`一键安全 Kill`。

### 2.3 【AI Copilot 智能助手全局抽屉 (Copilot Drawer)】
- **双模响应**：顶层展示大模型深度因果推理（Markdown 渲染与代码高亮），底层展示结构化指标卡片与引用事实。
- **一键智能体检 (Quick Health Check)**：仪表盘环形图展示 5 维健康得分，直观罗列风险扣分项与加固建议。

## 3. 交互微动效与无障碍响应体验

1. **实时数据流光脉冲 (Live Pulse)**：
   - 当 SSE 接收到新增活动告警时，顶部对应告警角标产生 0.6s 的发光呼吸脉冲动效。
2. **骨架屏渐进加载 (Skeleton Shimmer)**：
   - 图表与复杂拓扑在数据加载期间呈现深灰微光骨架占位，杜绝白屏与页面跳闪。
3. **响应式断点适配**：
   - 适配 1920x1080 (标准桌面)、2560x1440 (宽屏控制台) 及 1366x768 (笔记本)，栅格自动伸缩。
